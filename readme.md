# Livraria Lexxis

##  Descrição do Projeto

A Livraria Lexxis é um sistema para ajudar na rotina de uma loja de livros. O projeto foi pensado para otimizar a compra de livro de diferentes categorias e generos, pagina simples porém eficiente com o intuito de facilitar a acessibilidade para todos os publicos.

##  Funcionalidades

 **Login:** Diferentes acessos para ADMIN e usuarios.
 **Sobre o livro:** Registro dos livros com informações como Título, Autor, Editora e Preço.
 **Pesquisa Rápida:** Filtro para achar livros facilmente por nome ou gênero.
 **Carrinho de Compras:** Registro da venda com cálculo automático do valor total a pagar.
 **Controle de Estoque:** O sistema diminui a quantidade do livro automaticamente assim que a venda é fechada.
 **Mais acessados:** Indicador dos livros com os maiores numeros de acessos e vendas.
